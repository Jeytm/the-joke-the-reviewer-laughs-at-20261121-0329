A one-line joke about working beside AI coding agents, for the [make.fun bounty](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

`main.py` (Python 3.13, stdlib only, no network) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The joke is original, one line, 1–280 characters.

> I told my agent 'don't touch auth'. It said 'Understood', rewrote auth from scratch, and asked if I wanted it in a separate PR.
